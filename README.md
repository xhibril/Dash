# Dash

Full-stack URL shortener with analytics.

![Dash demo](docs/demo.gif)

## Demo
https://dash.xhibril.dev

> ⚠️ The demo may occasionally be unavailable if the backend is inactive to reduce hosting costs.

## Overview
Create short links and track usage with time-based stats.

## Tech Stack
- Java 17
- Spring Boot
- MySQL
- React

## Features
- Custom short links
- Click tracking
- Daily, weekly, monthly stats
- Rate limiting
- Authentication



## Run Locally

```bash
git clone https://github.com/xhibril/Dash.git
cd Dash
mvn spring-boot:run
